# 건강 커뮤니케이션 조별활동

"커뮤니케이션이 할 수 있는 것과 없는 것" 수업의 조별활동 페이지.

- `index.html`: 건강 이슈 사례 뱅크. 조별로 카드를 뽑고 사건 개요와 참고 자료를 본다.
- `info-source-tool.html`: 정보 접촉 기록. 조 만들기, 정보 입력, AI 분석, 우리 판단, 조별 기록표 5단계.

입력한 기록은 각자의 브라우저에만 저장되며 어디로도 전송되지 않는다.

이 저장소의 파일은 생성물이다. 원본과 생성 스크립트는 별도 저장소의 `class-materials/build/` 에 있다.
