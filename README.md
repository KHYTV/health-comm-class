# 건강 커뮤니케이션 조별활동

"커뮤니케이션이 할 수 있는 것과 없는 것" 수업의 조별활동 페이지.

- `index.html`: 건강 이슈 사례 뱅크. 조별로 카드를 뽑고 사건 개요와 참고 자료를 본다.
- `info-source-tool.html`: 정보 접촉 기록. 조 만들기, 정보 입력, AI 분석, 우리 판단, 조별 기록표 5단계.

입력한 기록은 각자의 브라우저에만 저장되며 어디로도 전송되지 않는다. (w13 제외)

## w13: 감기약 아세트아미노펜 체크 (11/25 개인활동)

- `w13/index.html`: 학생용. 학번·학과·이름 입력, 감기약 2종 이상 함량 사진, 고정 기준(1회 1,000mg·서방정 1,300mg, 1일 4,000mg, 성분 중복)으로 주의 결과, 한 줄 평 제출. 사진 글자 읽기는 브라우저 안(Tesseract.js)에서만 처리한다.
- `w13/admin.html`: 관리자용. 비밀번호로 제출 현황을 보고 엑셀(.xlsx)로 내려받는다.
- `w13/apps-script.gs`: 제출을 Google 스프레드시트에 저장하는 Apps Script. 설치 방법은 파일 머리말 참고.
- `w13/config.js`: Apps Script 웹 앱 주소(`APAP_ENDPOINT`). 비어 있으면 학생 페이지는 'LMS용 제출 파일 내려받기'로만 동작한다.

w13 파일은 이 저장소에서 직접 작성했다(생성 스크립트 없음).

이 저장소의 파일은 생성물이다. 원본과 생성 스크립트는 별도 저장소의 `class-materials/build/` 에 있다.
